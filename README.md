# Planet Terraforming

A co-op sandbox and automation game for up to 8 players, built on a falling-sand engine. You are terraformers preparing an alien planet for human habitation: mine the caves, sell minerals to Earth, grow plants in biodomes, lay pipes, program robots, and raise the oxygen until the colony ship can land.

This branch is in progress. The design and the progress log are in `docs/terraforming-plan.md`.

## Running

```sh
cargo run                               # main menu
cargo run -- --singleplayer --seed 1    # straight into a new world
```

Two players on one machine, without Steam:

```sh
cargo run -- --host-lan --name Ada
cargo run -- --join-lan 127.0.0.1 --name Grace
```

## Layout

| Crate | Purpose |
|---|---|
| `crates/sim` | Bevy-free simulation: the cell world, planet generation, and the colony rules (`colony/`) |
| `crates/net` | Wire protocol and the Steam and TCP transports |
| `crates/game` | Bevy client: session (host/client), rendering, input, UI, audio |

Art and audio are generated by the scripts in `tools/` and committed under `assets/`.
