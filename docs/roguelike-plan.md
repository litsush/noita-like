# Descent to the Core: implementation plan

A Spelunky-style roguelike built on the existing falling-sand simulation. You dig down through a
simulated planet to touch its core. Every upgrade changes how you interact with materials.

## Architecture

The existing split stays:

| Crate | Owns | Rule |
|---|---|---|
| `sim` | Materials, cell rules, world generation, explosions, ballistic cell particles, simulation events | No Bevy. Everything here is deterministic from the seed and covered by unit tests. |
| `net` | Wire protocol and transports | Untouched, except a protocol version bump for the new materials. |
| `game` | Bevy app: menus, sandbox/multiplayer session, the roguelike run, rendering, lighting, audio, UI | Presentation and player-facing rules. |

### New simulation state (designed to be syncable)

- **Material table (`material.rs`).** Grows to about 27 materials. New properties replace special cases: `hardness`, `heat` (emission, negative for cold), `conductive`, `corrosive`, `acid_resistant`, `explosive` (blast radius), `light` (RGB emission), `growth` (spread chance per random tick), `climbable`, `value` (ore).
- **Per-cell `life` byte, reused by material.** Lifetime for fire and gas, charge for conductive liquids (electricity), and a collapse countdown or settled flag for gravel. It is already part of the chunk encoding, so it replicates for free.
- **Random ticks.** A few random cells per chunk per tick, including sleeping chunks, for slow processes: fungus and frost growth, ice melting, heat cracking stone, vents puffing steam, metal sparking. Sleeping chunks still cost nothing otherwise.
- **`World::events`.** A per-tick list of `SimEvent`s (explosion, sizzle, acid dissolve, obsidian formed, gas ignited, collapse started, electrified). The game drains it for audio, particles, damage and achievement tracking. A host would forward these events to clients.
- **`World::particles`.** Material-carrying cells in ballistic flight (explosion debris, sprays, thrown liquids). They land back into the grid. This is sim state, so it is deterministic.
- **Worldgen output.** `worldgen::generate_descent(seed) -> Descent { world, spawns, layers }`. `spawns` lists chests, altars, shrines, creatures and the core as plain data, so the game turns them into entities and a host could send the same list.

### Game side

- **`AppState`.** Gains `Run`. Sandbox and multiplayer keep using `InGame` with the same `Session`. A run is a `Session` with `Role::Offline` plus a `Run` resource, so world rendering, the camera and upload code are shared.
- **World rendering.** Split into 256×256 texture tiles, so a tall 512×4096 world only re-uploads the tiles that changed. Visible chunks are re-shaded every few frames for liquid shimmer and lava, fungus and crystal glow.
- **Lighting.** A CPU light map at half resolution around the camera, built by 4-direction sweep propagation (Terraria style). Solids attenuate light strongly and air weakly. Sources are emissive materials, the headlamp, torches and the core. It is drawn as a smooth darkness overlay, and sky light fades out with depth.
- **New `game` modules.**
  - `run/` holds the run state, player verbs, health and hazards, items, achievements, save file, creatures and entities.
  - `fx.rs` holds cosmetic particles, screen shake and hit-stop.
  - `audio.rs` holds sound effects with distance falloff and rate limiting, plus layer ambience and music.
  - `ui/` holds the pixel theme and font, HUD, menus and summary screens.
- **Persistence.** `save.json` lives in the platform data dir (`$XDG_DATA_HOME/sbct`, `%APPDATA%\sbct`, `~/Library/Application Support/sbct`). A missing file means a fresh save. A corrupt file is backed up to `save.json.bak` and the game starts fresh.

### Assets

Generated by stdlib-only Python scripts and committed:

- `tools/gen_art.py` writes the sprite sheets, backgrounds and pixel font to `assets/`.
- `tools/gen_audio.py` writes WAV sound effects, ambience and music to `assets/audio/`.

## Content

### Layers

The world is 512×4096 cells.

| Layer | Depth | Contents |
|---|---|---|
| Crust | 0–960 | Dirt, stone, wood roots, water pockets, sand, oil seams |
| Upper Mantle | 960–1920 | Basalt, magma veins, steam vents, unstable gravel ceilings, gas pockets |
| Deep Mantle | 1920–2880 | Crystals, glowing fungus, acid pools, explosive gas chambers, gravel-filled pressure fractures |
| Outer Core | 2880–3700 | Liquid metal, ferrite (conductive solid), extreme heat, sparks |
| The Core | 3700–4096 | Core-shell chamber with one entrance, holding the core |

Set pieces per layer:
- Flooded ruin
- Abandoned mine with explosive crates
- Gas chamber
- Magma chamber with a fragile bridge
- Crystal cavern
- Metal foundry

Each layer has one altar (a free item). Shrines (items bought with ore) appear in layers 2 to 4. Chests are scattered through every layer.

Everything except the core shell is diggable, so a route down always exists. Meandering worm tunnels give several natural routes with different hazards. The tunnels are partly plugged with soft material, so the way down isn't obvious.

### Achievements (13)

The 11 achievements above unlock items. Two more unlock starting loadouts:
- **Untouched** (reach layer 2 without taking damage) unlocks the Gifted loadout, which starts with a random unlocked item.
- **Core Breaker** (win) unlocks the Excavator loadout.

## Milestones

Each milestone ends with a runnable game and a commit.

1. Materials and interactions in `sim`, with tests
2. Layered world generation down to the core, with set pieces
3. Player verbs, health and hazards, win and death
4. Items, achievements, persistence
5. Art, animation, particles and lighting
6. Audio
7. UI polish and the full menu flow
8. Balancing pass and bug fixing
