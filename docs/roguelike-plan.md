# Descent to the Core: implementation plan

A Spelunky-style roguelike built on the existing falling-sand simulation. You dig down through a
simulated planet to touch its core. Every upgrade changes how you interact with materials.

## Architecture

The existing split stays:

| Crate | Owns | Rule |
|---|---|---|
| `sim` | Materials, cell rules, world generation, explosions, ballistic cell particles, simulation events | No Bevy. Everything here is deterministic from the seed and covered by unit tests. |
| `net` | Wire protocol and transports | Untouched, except a protocol version bump for the new materials. |
| `game` | Bevy app: menus, sandbox/multiplayer session, the roguelike run, rendering, lighting, audio, UI | Presentation and player-facing rules. |

### New simulation state (designed to be syncable)

- **Material table (`material.rs`).** Grows to about 27 materials. New properties replace special cases: `hardness`, `heat` (emission, negative for cold), `conductive`, `corrosive`, `acid_resistant`, `explosive` (blast radius), `light` (RGB emission), `growth` (spread chance per random tick), `climbable`, `value` (ore).
- **Per-cell `life` byte, reused by material.** Lifetime for fire and gas, charge for conductive liquids (electricity), and a collapse countdown or settled flag for gravel. It is already part of the chunk encoding, so it replicates for free.
- **Random ticks.** A few random cells per chunk per tick, including sleeping chunks, for slow processes: fungus and frost growth, ice melting, heat cracking stone, vents puffing steam, metal sparking. Sleeping chunks still cost nothing otherwise.
- **`World::events`.** A per-tick list of `SimEvent`s (explosion, sizzle, acid dissolve, obsidian formed, gas ignited, collapse started, electrified). The game drains it for audio, particles, damage and achievement tracking. A host would forward these events to clients.
- **`World::particles`.** Material-carrying cells in ballistic flight (explosion debris, sprays, thrown liquids). They land back into the grid. This is sim state, so it is deterministic.
- **Worldgen output.** `worldgen::generate_descent(seed) -> Descent { world, spawns, layers }`. `spawns` lists chests, altars, shrines, creatures and the core as plain data, so the game turns them into entities and a host could send the same list.

### Game side

- **`AppState`.** Gains `Run`. Sandbox and multiplayer keep using `InGame` with the same `Session`. A run is a `Session` with `Role::Offline` plus a `Run` resource, so world rendering, the camera and upload code are shared.
- **World rendering.** Split into 256×256 texture tiles, so a tall 512×4096 world only re-uploads the tiles that changed. Visible chunks are re-shaded every few frames for liquid shimmer and lava, fungus and crystal glow.
- **Lighting.** A CPU light map at half resolution around the camera, built by 4-direction sweep propagation (Terraria style). Solids attenuate light strongly and air weakly. Sources are emissive materials, the headlamp, torches and the core. It is drawn as a smooth darkness overlay, and sky light fades out with depth.
- **New `game` modules.**
  - `run/` holds the run state, player verbs, health and hazards, items, achievements, save file, creatures and entities.
  - `fx.rs` holds cosmetic particles, screen shake and hit-stop.
  - `audio.rs` holds sound effects with distance falloff and rate limiting, plus layer ambience and music.
  - `ui/` holds the pixel theme and font, HUD, menus and summary screens.
- **Persistence.** `save.json` lives in the platform data dir (`$XDG_DATA_HOME/sbct`, `%APPDATA%\sbct`, `~/Library/Application Support/sbct`). A missing file means a fresh save. A corrupt file is backed up to `save.json.bak` and the game starts fresh.

### Assets

Generated by stdlib-only Python scripts and committed:

- `tools/gen_art.py` writes the sprite sheets, backgrounds and pixel font to `assets/`.
- `tools/gen_audio.py` writes WAV sound effects, ambience and music to `assets/audio/`.

## Content

### Layers

The world is 512×4096 cells.

| Layer | Depth | Contents |
|---|---|---|
| Crust | 0–960 | Dirt, stone, wood roots, water pockets, sand, oil seams |
| Upper Mantle | 960–1920 | Basalt, magma veins, steam vents, unstable gravel ceilings, gas pockets |
| Deep Mantle | 1920–2880 | Crystals, glowing fungus, acid pools, explosive gas chambers, gravel-filled pressure fractures |
| Outer Core | 2880–3700 | Liquid metal, ferrite (conductive solid), extreme heat, sparks |
| The Core | 3700–4096 | Core-shell chamber with one entrance, holding the core |

Set pieces per layer:
- Flooded ruin
- Abandoned mine with explosive crates
- Gas chamber
- Magma chamber with a fragile bridge
- Crystal cavern
- Metal foundry

Each layer has one altar (a free item). Shrines (items bought with ore) appear in layers 2 to 4. Chests are scattered through every layer.

Everything except the core shell is diggable, so a route down always exists. Meandering worm tunnels give several natural routes with different hazards. The tunnels are partly plugged with soft material, so the way down isn't obvious.

## Progress log

- **M0:** plan written. Art and audio generators built in parallel by helper agents.
- **M1:** expanded the material table to 31 materials with property-driven rules. Added acid, electricity, frost, explosions, gravel cave-ins, fungus growth, heat cracking and melting, ballistic particles, random ticks and sim events. 23 unit tests.
- **M2:** `descent.rs` layered world generation with set pieces, altars, shrines, chests, creatures and the core chamber. Tests cover determinism, content and that the core is reachable. Added the `descent_map` example for visual checks.
- **M3:** the run loop: player verbs, hazards, entities, creatures, items, achievements, save file, HUD and summary. An autoplay bot and screenshot flags allow unattended play-testing.
  - Play-testing found that the dig hole was narrower than the player (the player stood on pillars). Fixed by widening the dig and narrowing the collision box.
  - Achievements were firing from natural world activity. They now only count events near recent player actions.
- **M5:** half-resolution light map with sweep propagation, per-layer parallax backgrounds, a sky mask, rendering of in-flight particles, ambient effects (embers, smoke, fizz, sparks, splashes).
- **M6:** audio plugin with positional falloff, per-sound rate limits and volumes, layer ambience, menu music and volume settings.
- **M7:** full menu flow: new run with loadout and seed, unlocks screen, settings, multiplayer and sandbox. Pixel theme, hover and click sounds, fade transitions.
  - Performance went from 21 to 60 FPS in debug builds. Changes: simulating only chunks near the player, letting settled gas sleep, shading only visible chunks, and compiling the game crate at opt-level 2 in dev.
- **M8:** balancing. Changes: burial now displaces powder instead of killing; heat tuning; achievement thresholds; cause of death is the largest hit; clippy clean.

## Known gaps

- **Run length unmeasured:** the 10–20 minute target for a skilled player couldn't be checked. The bot is a test tool, not a skilled player.
- **Run state isn't synced for multiplayer yet:** see the README's multiplayer section.
- **No mid-run save:** "Continue" means retrying a seed from the summary or the New Run screen.
- **Single-threaded simulation:** the active region keeps it fast. Checkerboard multithreading is the next performance step.

# Part B: the wizard rework ("The Last Apprentice")

You play an apprentice elemental wizard descending to the heart of the world to complete your training. Many apprentices went down before you, and most never came back. The tone is mystical dark fantasy with dread: darkness, isolation, things moving at the edge of your light, and the remains and journals of those who failed.

What stays: the falling-sand simulation, the layered descent, permadeath, seeds, achievements unlocking content, and the main rule that every upgrade changes how you interact with materials rather than tweaking numbers.

## Core changes

- **The staff replaces every tool.**
  - *Dig spell:* the old pick, cast from the staff in both dig modes. Speed still depends on hardness. It draws a visible beam with a casting sound, and is free (no mana).
  - *Light orb:* replaces torches. It's cast toward the cursor, sticks where it lands or drifts slowly, flickers, and fades over 60 s. It has 3 charges that recharge in 25 s each. It only ignites flammables if you know at least one Pyromancy scroll.
  - *Staff glow:* can be dimmed with a key (default L). Darkness is a real choice because lightseekers hunt light.
- **Rope is removed completely:** material, input, HUD, art, sound and loadouts.
  - Climbing out without upgrades relies on the high jump, wall climb, wall jump (which now refreshes half your climb stamina), and dig-spell steps.
  - Terramancy (Stone Shape, Earthen Grip), Aeromancy (Updraft, Levitate), Mycomancy (Mycelial Bridge) and Blink add more ways up.
- **Shards replace ore.** The `Ore` material becomes **Shard Vein**: dark rock with glowing cyan flecks that emits a little light. Digging it drops **aether shards**, glowing pickups pulled toward you when you're near. Chests and remains also hold shards, and shrines sell scrolls for them. The purple **Crystal** material stays as decoration and is clearly different.
- **Mana:** one shared mana bar (100, regenerating 8/s). Active spells cost 12–40 mana and have short cooldowns. The decision each moment is which spell to spend on; light-orb charges stay separate so lighting is never a mana dilemma.

## Schools and specialization

There are eight schools, each tied to materials in the simulation:

| # | School | Materials |
|---|---|---|
| 0 | Pyromancy | Fire, lava, heat, embers |
| 1 | Hydromancy | Water, steam, flooding, swimming |
| 2 | Terramancy | Stone, sand, gravel, shaping and collapsing terrain |
| 3 | Cryomancy | Ice, frost, freezing liquids |
| 4 | Aeromancy | Wind, gas, pushing powders and liquids, levitation |
| 5 | Fulmancy | Lightning, sparks, conduction through water and metal |
| 6 | Alchemy | Acid, explosives, transmutation |
| 7 | Mycomancy | Fungus, growth, spores, rot |

Pyromancy, Hydromancy, Terramancy and Mycomancy are unlocked from the start; the others unlock through achievements.

**Specialization rules:**
1. At the start of a run you pick your first school from the unlocked ones.
2. The first altar you use is an **attunement altar**. It offers 3 scrolls from 3 different other unlocked schools. Taking one locks in your second school. The world places an attunement altar early in the Whispering Crust, near the middle of the shaft.
3. After that, chests, altars and shrines only offer scrolls from your two schools plus neutral scrolls. Before attunement they offer first-school and neutral scrolls.
4. Scrolls from other schools still turn up on fallen apprentices. Picking one up breaks it down into 15 shards instead.
5. Learning at least one scroll from each of your two schools awakens that pair's **fusion**, granted automatically with a toast. Discovered fusions are saved and shown in the Unlocks screen.

## World re-theme

Layers keep their depths and generation, retuned for the theme:

| Old layer | New name | Retune |
|---|---|---|
| Crust | The Whispering Crust | — |
| Upper Mantle | The Drowned Halls | More water and flooded halls; lava rarer |
| Deep Mantle | The Fungal Abyss | Much more fungus, spores and acid |
| Outer Core | The Molten Sanctum | — |
| Core | The Heart of the World | The core becomes the **Trial**, a rune-ringed heart; touching it completes your training |

**Lore and remains:**
- **Fallen apprentices** (6–8 per run): skeletal remains in robes. Searching one gives shards and sometimes a scroll, usually from a random school (off-school scrolls break into shards). Each also holds a **journal page**.
- **Journal pages:** about 30 short lines building the lore and dread, read in a parchment popup. Pages read are saved.
- **Ritual circles:** brick and crystal rings in the rock. **Ruined shrines** re-skin the shop shrines.
